# Böse Zeichen im Titel #1

- Was, wenn der Titel [[unerlaubte Zeichen]] enthält?
- Obsidian will den Titel in den Filename verschieben, löscht aber die unerlaubten Zeichen.
- Wir könnten dann darüber nachdenken, den Titel ausnahmsweise im Markdown stehen zu lassen, so dass keine Informationen verloren gehen.
